SERVERLESS KIOSK HANDOFF

Double-click index.html to open the kiosk. No server or launcher is needed. The media folder starts empty, so the grid shows placeholders until you add images or videos.

Click Choose media folder and select the media folder beside index.html. In Chrome or Edge, the kiosk checks that folder every 10 seconds, shows supported files placed there, and rotates the display about once a minute. The browser may ask you to grant access again when you reopen the page. Press F2 to reopen the folder chooser.

Show empty kiosk closes the folder chooser and leaves placeholders visible. To display files you add later, press F2 and connect the media folder.

Supported files: PNG, JPG, JPEG, GIF, WebP, AVIF, MP4, MOV, WebM, M4V. Video playback also depends on browser codec support.

The kiosk preserves its portrait 3:4 layout and scales to fit the browser viewport. Use F11 for browser full screen mode.
